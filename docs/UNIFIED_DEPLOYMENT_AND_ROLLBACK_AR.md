# نشر المشروع الموحد وخطة الرجوع

## نقطة الأساس قبل الدمج

- `saweeg-home/main`: `ff57872401efada0a775d875fd42c67aa385d818`.
- `saweeg-menu/main`: `53a19ea25ac672df13d539e1cead6bf926bcb8cc`.
- فرع تنفيذ الدمج: `feat/unified-home-menu` داخل `saweeg-home`.
- فرع التحويل الانتقالي: `chore/redirect-to-unified-menu` داخل `saweeg-menu`.

لم يتغير `main` أو DNS أو إعداد Pages أثناء التجهيز المحلي.

## ترتيب الإطلاق الآمن

1. ادفع فرع `feat/unified-home-menu` فقط وافتح Pull Request إلى `saweeg-home/main`.
2. تأكد من نجاح GitHub Actions ومراجعة الفرق. طلب الدمج يبني ولا ينشر.
3. بعد الاعتماد، ادمج Pull Request في `saweeg-home/main`. هذا ينشر البوابة والمنيو الموحدين إلى `go.saweegsa.com`.
4. افحص الصفحة الرئيسية، المشاركات، `/menu/`، `/menu/en/`، فرعي `maqsed` و`bustan`، والصور على الإنتاج.
5. لا تغيّر الرابط القديم حتى تنجح الخطوة السابقة.
6. بعدها ادفع فرع `chore/redirect-to-unified-menu` وافتح Pull Request إلى `saweeg-menu/main`.
7. بعد مراجعته، ادمجه ليصبح `menu.saweegsa.com` صفحة تحويل انتقالية فقط.
8. اختبر الروابط القديمة العربية والإنجليزية مع معاملات إضافية وأجزاء `#` من جهاز خارج الحساب.

## ما تنشره العملية الموحدة

Workflow في `.github/workflows/deploy.yml` يستخدم Node.js 22 وpnpm 11.19.0، يثبت `pnpm-lock.yaml` دون تحديث، ثم يشغل البناء والفحص ويرفع `dist/` إلى GitHub Pages. النشر محصور في `main`؛ الفروع وPull Requests تنفذ البناء فقط.

يبقى `public/CNAME` مساويًا لـ`go.saweegsa.com`. لا يحتاج نشر المشروع الموحد إلى Netlify أو تعديل سجل `go`.

## الرجوع قبل تفعيل التحويل القديم

إذا فشل المنيو الموحد بعد دمج `saweeg-home` وقبل تغيير `saweeg-menu`:

1. لا تلمس `saweeg-menu`؛ سيستمر المنيو القديم بالعمل.
2. أنشئ Pull Request في `saweeg-home` يعكس Merge commit باستخدام `git revert`.
3. راجع البناء ثم ادمج Revert لإعادة نشر نسخة البوابة السابقة.
4. لا تستخدم force-push أو إعادة كتابة التاريخ.

## الرجوع بعد تفعيل التحويل القديم

إذا ظهر خلل بعد نشر التحويل:

1. أعد أولًا `saweeg-menu/main` إلى تطبيق المنيو السابق عبر Pull Request يعكس Commit التحويل؛ هذا يعيد الرابط القديم بسرعة.
2. بعد عودة المنيو القديم، اعكس Merge التوحيد في `saweeg-home` إذا كان الخلل في المشروع الموحد.
3. تحقق من الرابطين وGitHub Actions بعد كل خطوة.

يبقى التاريخ الكامل في Git؛ لا حاجة لحذف المستودع القديم أو نقل DNS أثناء الإطلاق الأول.

## حزمة التسليم

حزمة التسليم السابقة مؤرخة قبل الدمج وتمثل مستودعين منفصلين. لا تعدلها ولا تصفها بأنها نسخة موحدة. بعد اعتماد Pull Request والنشر والتحقق الحي، أنشئ حزمة نهائية جديدة من `saweeg-home/main` مع Commit النشر ونتائج فحص الإنتاج.
